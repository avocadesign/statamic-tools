Spacing

The grid and the spacing steps the blocks are built from, drawn with the site's own classes. Hatching marks space. The measurements are read from the page, so resize the window and they update.

Fluid grid

Twelve columns between two side margins. The column gap is fluid, --col-gap: {{ spacing:grid:gap }}, and blocks use the same gap between rows with gap-fluid-grid-gap. Declared in {{ spacing:grid:file }}.
