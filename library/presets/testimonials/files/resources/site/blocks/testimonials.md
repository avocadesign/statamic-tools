title: Testimonials
description: Quotes from the Testimonials collection, each with the person's name, role and an optional photo or logo, in a grid or as one featured quote.
---
## When to use

- Showing what clients or customers say about the business, on the home page, a service page or near a call to action.
- Under Display settings, set Layout to Featured quote for one strong testimonial between other blocks, or keep Grid for three or more.
- Set Testimonials to show to Chosen testimonials to pick the quotes that suit the page, such as quotes about one service.

## When not to use

- A single quote inside body copy, or a quote from someone who isn't a client, such as a press quote: use the Pull quote set in the text editor, which sits in the flow of the text.
- Reviews that need star ratings or a link to where they were posted: this block shows neither, so ask the developer.
- A long case study: use a project page, or Text and Media and text, because a testimonial is a short quote.

## Notes for AI

- Only use real testimonials, from people who have agreed to be quoted on the site with their name, role and any photo. Never invent a testimonial, a person or a role, even as a placeholder.
- Quote people's own words. Keep quotes short: one to three sentences, about 40 words, or up to about 60 words with Featured quote. When shortening a quote, cut words rather than rewording it, and never change its meaning.
- Don't add quotation marks: the block adds them.
- Each testimonial is an entry in the Testimonials collection, not text in the block. Add it to the collection first, then show it with this block.
- A photo shows as a small circle, so use a square crop around the person's face. Set Image type to Logo for a logo, which keeps its shape. Give the image alt text, such as the organisation's name for a logo.
- There is no random order, because the site may be published as static files, where a random order would be fixed when the site is built. Use Collection order with the strongest testimonial first, or Newest first.
- In Grid, show three testimonials, or six in two rows. Featured quote shows only the first testimonial.
- With Chosen testimonials and none chosen, the block shows testimonials in collection order.
- The preset installs three sample testimonials, whose photo is an image the site already had, such as a placeholder. Delete them before launch and add real ones.
