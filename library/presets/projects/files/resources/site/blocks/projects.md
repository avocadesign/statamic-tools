## When to use

- Showing recent work on the home page or a service page, with each card linking to the project's own page.
- A portfolio page that lists every project: set Number to show to All.
- Set Projects to show to Chosen projects to pick the projects that suit the page, in your own order, such as work for one service.

## When not to use

- Cards that link to ordinary pages, or cards with no page behind them: use Cards, because this block only shows projects.
- Photos from one project: use Gallery on the project's own page, which opens each photo larger.
- One project to feature with more text beside it: use Media and text, with a button to the project, because a card holds only a short summary.

## Notes for AI

- Each project is an entry in the Projects collection, with its own page at /projects/ followed by its slug. Build the project page from page builder blocks, under its page header, like any other page.
- Give every project a featured image with alt text and a summary, because its card shows both. The card crops the image to landscape (3:2), so choose images whose subject survives that crop.
- Keep summaries to one or two sentences, about 25 words, and titles to a few words, so the cards line up evenly.
- Set each project's date to when it was finished. The card shows its year, and Newest first and Oldest first sort by it.
- Show three projects, or a multiple of three, so the rows fill. Two or four projects form two columns, and one sits alone in the middle.
- With Chosen projects and none chosen, the block shows the three newest projects.
- The preset installs three sample projects, set to noindex, whose featured image is an image the site already had, such as a placeholder. Replace them with real projects, with their own images, before launch.
